# Artifact: FolioLingo Performance, Localization & Quizzes Blueprint (v0.3.0)

## Executive Summary
This design record documents the architectural evolution of FolioLingo from a single-tier reader to a two-tier low-latency philological engine with global native language localization and interactive section comprehension checks.

---

## 1. Problem Statement
1. **Word Lookup Latency**: In early iterations, clicking a word required full morphological analysis over an LLM call, introducing 1.5s–3.0s latency that broke reading flow.
2. **Fixed Language Pairing**: The initial reader was tied to English-Spanish pairings, limiting utility for non-English native speakers globally.
3. **Passive Retention**: Reading without testing often results in rapid vocabulary decay without structured recall mechanisms.

---

## 2. Architecture & Solution

### A. Two-Tier Low-Latency Philological Engine
- **Tier 1 (Instant <100ms)**:
  - In-memory client cache (`Map<string, BreakdownResult>`) guarantees 0ms repeated lookups.
  - Server route `/api/gemini/breakdown` configured with `thinkingConfig: { thinkingLevel: ThinkingLevel.LOW }` and concise JSON structure to deliver context translation and lemma in sub-second time.
- **Tier 2 (Progressive On-Demand Philology)**:
  - "Deep Philology & Grammar" accordion dynamically expands detailed linguistic morphology, tense/mood breakdown, and cultural etymology notes without blocking initial reading.

### B. Global Base Language Selector
- Supports 12 global languages: English, Turkish, Spanish, French, German, Italian, Portuguese, Russian, Arabic, Japanese, Korean, Chinese.
- Dual selectors in both the top `Navbar` and inside the active `WordBreakdownPopover` for instant on-the-fly switching.

### C. Interactive Section Comprehension Quizzes
- At the end of each reading section, readers unlock a 3-part interactive quiz:
  1. *Narrative Comprehension*: Tests understanding of key section events.
  2. *Contextual Vocabulary*: Cloze-style test on newly introduced vocabulary.
  3. *Grammatical Inference*: Tests idiomatic phrasing.
- Awards +25 XP to the user's daily streak and habit ledger.
